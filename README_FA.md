# راهنمای بنچمارک بازتولیدپذیر CAAdapFL

این بسته برای نسخهٔ Marked5 مقاله آماده شده است و هنوز در GitHub منتشر نشده.
کد متعلق به نویسندگان تحت Apache2.0 عرضه می‌شود؛ شرایط داده‌ها جداست.

چهار مجموعهٔ اصلی با513 بستهٔ fit تکمیل‌شده حفظ شده‌اند: اجرای اصلی283،
کنترل‌های solar/IMD/GLDAS21 تعداد90، ظرفیت و اجزا100، و اشتراک اطلاعات40.
پیش‌بینی خام، تنظیمات، seedها، checkpoint، هزینه‌ها و هش‌های خروجی در شش
فایل ZIP نتایج هستند. نام مدل‌های خروجی و شاخه‌های checkpoint تعداد fit نیستند.

۱. ZIP سورس را در مسیری کوتاه باز کنید و محیط Python3.12.14 و وابستگی‌ها را
طبق README انگلیسی نصب کنید. اجرای مدل‌ها روی CPU است.
۲. هر شش فایل نتایج را کنار هم قرار دهید؛ سپس اجرا کنید:

```text
python benchmark.py doctor
python benchmark.py install --assets PATH_TO_RELEASE_ASSETS
python benchmark.py verify --suite all
python benchmark.py replay --suite all
python benchmark.py tables --output publication/tables_new
python benchmark.py figures --output publication/figures_new
```

verify محاسبات را مستقل بازبینی می‌کند؛ replay از مدل ذخیره‌شده پیش‌بینی
می‌گیرد. این دو آموزش تازه انجام نمی‌دهند. برای آموزش تازه، دستور train با
--execute و پوشهٔ تازه لازم است. نوت‌بوک اجراشده در notebooks قرار دارد.

ورودی‌های IMD در بستهٔ عمومی نیستند. پیش‌بینی و نتایج تولیدشدهٔ این کنترل
حفظ شده‌اند، اما بازپخش شاخهٔ IMD تا تهیهٔ دادهٔ بومی و import با وضعیت
PARTIAL_UNAVAILABLE و کد خروج2 متوقف می‌شود؛ این وضعیت موفقیت کامل نیست.
بازسازی44 فایل بومی و سپس8 فایل پذیرفته‌شده با هش یکسان محلی آزموده شد.
راهنمای دقیق دو محیط متفاوتِ استخراج IMD و مدل در docs/DATA_ACCESS.md است.

شکل‌های اصلی مقاله محفوظ‌اند؛ شکل‌های بازتولیدی عددی ممکن است چیدمان
متفاوتی داشته باشند. سال‌های2017–2024 قبلاً دیده شده‌اند و آزمون مستقل جدید
نیستند. آماده‌سازی این بسته به معنی پذیرش مقاله یا اثبات برتری عمومی فدرال نیست.

برای انتشار، فقط فایل‌های فهرست source_manifest.json را وارد Git کنید و شش
ZIP نتیجه را به Release اضافه کنید. پوشهٔ private_inputs_DO_NOT_UPLOAD را
منتشر نکنید. گزارش کنترل نهایی در docs/VALIDATION.md و ترتیب انتشار در
docs/DEPOSIT.md آمده است.
