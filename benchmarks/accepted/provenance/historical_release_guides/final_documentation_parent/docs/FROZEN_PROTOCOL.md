## 1. Objective and estimand

Estimate retrospective one-month-ahead skill for monthly CHIRPS v2 final rainfall totals in five fixed study clients. Compare true shared-parameter neural federation with matched centralized and local models, explicitly named personal diagnostics, graph-personal variants and genuine component removals. Evaluate the separately named static hybrid router on its fixed six-classical-expert pool. It has no graph or neural expert and does not feed the parameter-federation comparison. Do not reinterpret the historical Guardian/tree-routing leaderboard as evidence of parameter federation.

The main accuracy estimands are the means, across the five paired training seeds, of equal-client macro residual R² and equal-client macro RMSE on the common 96 target months in 2017–2024. R² alone selects checkpoints and tuning candidates; RMSE is co-reported without a separate search. Per-seed and per-client values are retained. It is not the score of an implicit five-seed prediction ensemble. Pooled R², different cohorts, constrained predictions and different model identities are separately named estimands.

The study is conditional on the fixed five clients and revised archive snapshot. It does not estimate nationwide generalization, unseen-region transfer, independent-client uncertainty, real-time vintage performance or flood-warning reliability.

## 5. Prespecified representations and preprocessing

CORE has 14 channels: first/second target-month sine/cosine harmonics; eligible rainfall lags 1/2/5/11 relative to row origin; shifted means and population SDs for windows 3/6/12. CLIMATE adds six corrected indices and ENSO×IOD, giving 21 channels. FULL adds the 22 accepted main meteorological channels, giving 43. Neural sequence length is twelve; climate context has seven channels for CLIMATE/FULL and zero for CORE, which requires disabled embedding.

Input standardization uses training-only per-channel population mean and SD. Its reference sample is one last-origin row per gradient-training target/client, avoiding unequal weighting from duplicated sequence rows. Clients share int64 count and float64 sums/squared sums; server broadcasts mean/SD. Near-constant SDs below 1e-12 become one. This is a plain summary-sharing protocol, not secure aggregation. Local target population mean/SD and the 80th percentile event threshold use only the client's 299 gradient-training labels.

No evaluation-informed feature screening, missing-feature substitution or test-ranked input choice is permitted. CORE/CLIMATE/FULL are predetermined controls. TRAIN_SELECTED chooses only among these three using pooled latest-row Ridge α=10, with preprocessing refit within three chronological gradient-period folds: fit through 1995-11 → score 1996-01–1998-12; fit through 2000-11 → score 2001-01–2003-12; fit through 2004-11 → score 2005-01–2007-11. Use the highest mean fold macro R² only if its gain over CORE is at least 0.002; otherwise retain CORE. Exact ties prefer fewer features. This is a bounded group selector, not broad variable screening. TRAIN_SELECTED aliases the chosen existing group and is not counted as an independent extra representation.

Classical Ridge/ExtraTrees/RandomForest controls use the latest sequence row, pooled raw targets or separate local targets, without a client-ID predictor. Ridge uses a training-only StandardScaler and α=10; trees use raw inputs, 256 trees, minimum leaf 3, max_features=1.0 and two library threads. A separately labelled FULL ExtraTrees flattened-sequence sensitivity uses all 12 rows. A separately labelled `client_normalized_pooled_ET_FULL_latest` comparator uses training-only client target mean/SD, pooled standardized-target loss and client-specific inverse decoding, without client-ID input. It matches the neural central target-loss/decode population more closely than raw pooled trees, while preserving those original raw controls. Shared cohort does not imply identical representation or objective.

For classical stacking, any out-of-fold construction must split unique calendar target months in forward order, keeping all clients of one target month together, and fit all fold transforms only on its past training months. Shuffled folds or sorting rows while splitting the same month across train/validation are prohibited. Any horizon/availability purge is applied at the true target/source boundary.

Recurrent/head dropout are 0.2/0.3. The nonlinear climate-conditioned score is an explicit revised architecture; the previous linear constant-climate score cancels inside temporal softmax. Synthetic held-hidden intervention and zero-embedding controls are required. Do not load old linear-attention states into the revised architecture.

Baseline objectives share MSE in local standardized target space and BCE coefficient 0.3 unless the auxiliary head is ablated. The frozen runner uses Adam and gradient norm clipping 5.0. SGD is supported by the module but is not in this run. Optimizer state resets each round for all streams; persistent personal parameters remain distinct from persistent optimizer state. Strict config rejects unknown arguments.

A sequential development search uses seed 42 and FULL inputs only. First select one shared learning rate from {0.001, 0.003} by global FedAvg outer-validation macro R². Then select μ from {0.001, 0.01, 0.1} separately for FedProx global, Ditto personal, each of the three graph-personal methods, and CAAA global. Finally select CAAA additive coefficients from the 15 nonnegative quarter-simplex triples summing to one, plus the manuscript anchor (0.3,0.3,0.4), at its chosen LR and μ. This is 2+6×3+16=36 candidate fits, not a Cartesian grid. Exact candidate ties prefer the smaller LR, smaller μ, and coefficient anchor before lexicographic order. All candidates and their curves remain in the trial ledger. The single shared LR is a baseline-favoring convention, not proof that all algorithms receive their individually optimal LR.

Use frozen main FULL choices for all feature groups, identities, seeds and latency scenarios; no evaluation tuning is allowed. Component coefficients are the explicit fixed-anchor exception described below. μ is method-specific. Both global/personal CAAA identities use the same selected algorithm configuration and independently selected checkpoints. Outer validation is reused for finite hyperparameter and checkpoint selection, so it is development data; only the later retrospective cohort supplies final accuracy estimates. Candidate selection of each 60-round best checkpoint is disclosed as part of the search budget.

* Local ALCE uses each client's own gradient tensors without inter-client parameter aggregation.

## 7. Training-only graphs and routing scope

Main graph and sensitivity fits use gradient targets through 2007-11 only. An explicitly labelled training-envelope diagnostic may use through 2010-11 only with its explicit flag; it never silently replaces the main graph. Sensitivities correlate fit-only deseasonalized target rainfall with eligible raw index vectors.

Original graph: shifted cosine of the ENSO/IOD sensitivity vector. Enriched graph: equal 0.25 mean of shifted inter-client rainfall anomaly correlation, shifted cosine of within-client standardized twelve-month seasonal climatology, shifted cosine of six-index sensitivities, and `exp(-d²)` of standardized rainfall descriptors. Descriptors are population variance, coefficient of variation and JJAS fraction of annual calendar climatology; d² is mean squared standardized descriptor distance across fit clients. Uniform graph entries are one. Rows are normalized in the graph trainer.

Seasonal-cosine shifting, the JJAS descriptor and distance scaling are explicit revisions to underspecified manuscript choices. Constant correlations become zero; zero-norm cosine becomes zero then shifted to 0.5; constant standardized descriptors become zero; diagonals are one. Every degeneracy is recorded. Minimum default support is 24 paired samples and two observations in every calendar month; insufficient support fails.

CAAA equations contain no direct S term. The graph-personal baseline and any graph-transfer router expert are separate mechanisms. An experiment cannot be called `without graph` if its parent calculation never uses a graph.

The actual router pools are CORE and FULL, each with the same six latest-row raw-target classical experts ordered Ridge pooled/local, ExtraTrees pooled/local, RandomForest pooled/local. All five router controls reuse identical stored expert predictions: validation best expert, equal expert weights, validation convex blend, robust temporal convex blend, and temporal-OOF standardized Ridge stack (α=10). There is no global-only pool and no neural/graph expert in this bounded run. Pooling in three of six experts is privileged training access and remains explicit. These routers are separate controls, not ablations of the neural CAAA objective.

Fit provisional static per-client weights on 2011-01–2013-11, score them on 2014-01–2016-11, then refit final static weights on all 2011-01–2016-11 validation targets. The held-out routing score describes provisional weights, not the final refit. Best-expert exact ties select the first expert in the frozen ordering. Convex optimization uses simplex bounds [0,1], sum=1, equal initialization, SLSQP, ftol=1e-12 and maxiter=500; failed optimization fails the run. Each router bundle also fits the six exact expert configurations on three chronological training OOF folds (18 additional expert fits), keeping calendar months common across clients and requiring fit_end ≤ heldout target−2 months. The Ridge stack is trained on those training OOF predictions only.

The revised robust temporal objective is 0.65 overall calibration R² + 0.35 chronological last-half calibration R². Last half starts at zero-based index floor(n/2); its denominator is its own target TSS. This is **not** the manuscript tail-event R² criterion, and uses no non-global penalty or climate-dependent gate. It must be called a revised static temporal stability router, rather than an exact DPRC reproduction. The manuscript DPRC equation is underspecified in tail threshold, penalty and solver, and its exact empirical validation remains unresolved manuscript work. Fixed validation routes do not demonstrate time-dynamic routing.

## 9. Metrics, paired comparisons and uncertainty

Primary accuracy metrics: `R²_c=1−Σ(y−p)²/Σ(y−mean(y))²` and RMSE_c in mm, then arithmetic means over the five clients. R² selects models; RMSE does not independently select a model. NSE uses the same R² formula. MAE, Pearson r, original KGE and signed PBIAS are secondary with explicit per-client/macro/pooled naming. Use `PBIAS=100 Σ(y−p)/Σy`, so positive means underprediction; report absolute bias separately because signed client means can cancel. Constant-support/zero-denominator metrics are explicitly undefined, not silently zero. Preserve all raw negative predictions.

For every saved comparison, deltas are A minus B: `ΔR²=R²_A−R²_B` is better when positive; `ΔRMSE=RMSE_A−RMSE_B` is better when negative. Label the sign explicitly. Do not reverse RMSE signs in prose or figures without a renamed column. Compute macro differences from the same per-client metric definition used in the main table. Pooled differences receive a separate label. Display the five paired seed differences, mean difference, SD and uncertainty. Do not mix a pooled bootstrap point estimate with a macro table comparison.

Use 2,000 circular temporal-block replicates with NumPy default_rng seed 731: primary block length 12 months and prespecified sensitivities 6 and 24. Draw starts uniformly over 96 dates, wrap modulo 96, concatenate ceil(96/block_length) blocks and truncate to 96. The same dates are used jointly for all five clients, both models and every paired seed. Resample five training-seed indices with replacement and use those same indices for both methods. Recompute each client metric, macro-average, then average the paired seed metrics. Report percentile 2.5/97.5 intervals. No IID sampling of client-month rows, ensemble-prediction score or nationwide spatial inference is used. Undefined constant-target resamples fail rather than receiving metric floors. The three block lengths use a continuing RNG stream; each comparison restarts at seed 731.

The frozen 31-pair family comprises eight selected CAAA-global versus FedAvg/FedProx-global pairs across four groups; four personal FULL comparisons; five fixed-anchor CAAA component controls; one CORE climate-free pair; two enriched-versus-original/uniform graph pairs; three matched-latency pairs; and eight same-pool robust-router comparisons. The machine-readable protocol contains the exact labels. Aliased TRAIN_SELECTED pairs remain declared but are explicitly duplicate evidence when the chosen group matches an existing pair. Intervals are marginal 95% intervals, not multiplicity-adjusted simultaneous confidence bands.
