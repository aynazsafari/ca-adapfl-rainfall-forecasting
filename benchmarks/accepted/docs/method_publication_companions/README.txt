Method figure publication companions

Insert each standalone figure at its native width of 6.7 inches. Diagram labels are at least 10.5pt; PNG files are 2010 pixels wide at 300dpi. PDF and SVG files preserve vector text and shapes. The four *_with_caption.pdf pages combine the vector diagrams with the exact original captions in 10pt type, 12pt baselines and a 0.15-inch gap. Their heights are 8.150, 8.017, 7.550 and 7.617 inches.

captions.json and captions.txt are byte-identical to the frozen v3 captions. captions_print_10pt.txt is an optional line-wrap example; final captioned PDFs use DPI-matched wrapping. PDF extraction may insert whitespace inside kerned letter pairs, so PDF glyph order is checked ignoring whitespace; the drawn caption labels retain the exact original word sequence.

Both author and independent reviewer inspected all four PNGs at original resolution. Captioned PDF page geometry, text fonts, caption label bounds and glyph sequence were checked mechanically; no separate full-page PDF raster inspection is claimed. These are source-only layout derivatives. No accuracy, prediction, evaluation-truth, checkpoint or round-history data were opened. Frozen v3 originals, repo copies and scientific modules remain unchanged.
